# 40+ 项清单深度润色 (Deep-Polish Checklist)

对 8 大类逐项标记 ✅ / ❌ / ⚠️，输出精修稿与分级变更摘要。

## 1. 联系方式 (Contact)
- [ ] 手机号格式正确、可联系
- [ ] 邮箱专业（非纯数字 QQ 邮箱更优，非强制）
- [ ] 城市 / 求职状态 / 意向岗位标注
- [ ] 可选：GitHub / 技术博客 / 作品集链接
- [ ] 无敏感信息（身份证、过细住址）

## 2. 摘要 / 个人概述 (Summary)
- [ ] 有 2–4 行强概述
- [ ] 含关键经历标签（公司 / 方向）
- [ ] 含量化成果钩子
- [ ] 对齐目标岗位，无空话套话

## 3. 工作经历 (Experience)
- [ ] 每段以强动词开头
- [ ] 每条含量化结果
- [ ] 体现技术深度与业务价值
- [ ] 情境-行动-结果（STAR）清晰
- [ ] 时间倒序、格式统一
- [ ] 公司 / 部门 / 岗位 / 时间完整

## 4. 教育背景 (Education)
- [ ] 学校 / 专业 / 学位 / 时间完整
- [ ] 相关课程 / 荣誉可选列
- [ ] 突出 GPA / 排名（若优秀）
- [ ] 时间格式统一

## 5. 技能 (Skills)
- [ ] 分类清晰（语言 / 框架 / 中间件 / AI）
- [ ] 熟练度标注（熟悉 / 了解）
- [ ] 与目标岗位关键词对齐
- [ ] 无堆砌、无虚假

## 6. 语法与语言 (Language)
- [ ] 时态一致（已结束用过去时，进行中用现在时）
- [ ] 无错别字
- [ ] 强动词表应用
- [ ] 中英文混排加空格
- [ ] 无口语化 / 冗余

## 7. 排版 (Layout)
- [ ] 一页 / 两页控制
- [ ] 层级标题统一
- [ ] 字体字号一致
- [ ] 无表格 / 图片干扰 ATS（导出 PDF 除外）
- [ ] 留白合理、视觉节奏舒适

## 8. ATS 兼容 (ATS)
- [ ] 标准章节标题（工作经历 / 教育背景 / 技能）
- [ ] 关键词覆盖 JD
- [ ] 无分栏 / 文本框 / 图片
- [ ] 文件为可复制文本（非纯图片 PDF）
- [ ] 联系方式完整可解析

---

## 变更分级标准

- 🔴 **关键**：影响筛选或 ATS 解析，必须改（缺失量化、联系方式错误、ATS 不兼容）。
- 🟡 **重要**：明显提升竞争力（强动词、摘要、关键词对齐）。
- 🟢 **次要**：锦上添花（排版细节、课程罗列）。
- 💡 **建议**：可选优化（作品集、博客展示、求职信）。

## 强动词表（中英对照）

主导 / 设计 / 搭建 / 重构 / 优化 / 落地 / 打通 / 抽象 / 封装 / 串联 / 沉淀 / 推动 / 实现
Led · Designed · Built · Refactored · Optimized · Shipped · Drove · Implemented · Streamlined

> 慎用弱动词：「负责」「参与」「协助」单独出现时应补强为具体动作 + 结果。

## 量化指南

量化维度：性能（延迟 / 吞吐 / QPS）、规模（用户 / 请求 / 数据量）、业务（转化率 / 收入 / 成本）、效率（耗时 / 人力）、质量（准确率 / 可用性）。

公式模板：**通过 [动作] 使 [指标] 从 [X] 到 [Y]，[影响]。**

示例：
- 「将快队列 P99 响应时间从 >10s 降至 <3s」
- 「100 条会话处理耗时从 8500ms 降至 400–800ms」
- 「回答准确率提升至 85%+，研发效率提升约 30%」
